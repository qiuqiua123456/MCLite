MCLite 1.7.4  使用说明
======================================================================

这是一个轻量级 Minecraft 启动器，单个 exe，免安装。


一、怎么开始
----------------------------------------------------------------------
1. 双击  MCLite.exe  就能打开（第一次启动会慢几秒，是在解压自己）。
2. 如果 Windows 弹出「已保护你的电脑」：
   点「更多信息」→「仍要运行」。这是没买代码签名证书的正常提示。
3. 打开后先看「设置」页左上角的「游戏目录」：
   - 会自动找一个已有的 .minecraft（%APPDATA%\.minecraft 等）；
   - 想用别的目录，点「浏览」选，或者直接在输入框里改，再点右上角「保存设置」。


二、装一个游戏版本
----------------------------------------------------------------------
1. 顶部点「下载」。
2. 等它拉完版本清单（右上角会显示 共 xxx 个版本）。
3. 左边选版本号（一般选「正式版」里最新的一个）。
4. 点「下载并安装」。进度会显示百分比 / 文件数 / 速度。
5. 装完回到「开始」页，版本列表里就有它了，选中后点「启动游戏」。

想装 Forge / NeoForge / Fabric：
   在「下载」页选中一个已安装的版本 → 点「安装加载器…」→ 选加载器、选版本 → 安装。
   （Fabric 通常几秒，Forge / NeoForge 第一次要下一批依赖，可能要几分钟。）


三、登录
----------------------------------------------------------------------
默认是**离线登录**，玩家名可以随便填，不联网也能玩。

* 微软正版：点「开始」页的「账户」页签（或左下角头像）→「微软正版登录」，
  会显示 8 位设备码，按提示在浏览器打开 https://www.microsoft.com/link 输入即可。
* 第三方皮肤站（LittleSkin / MUA / Blessing Skin）：
  「账户」页签 →「第三方皮肤站登录」→ 选站点 → 点「打开认证页面」去网站注册 / 登录 →
  回到窗口填邮箱和密码 → 登录。之后启动游戏会自动带上 authlib-injector，
  游戏里就能看到皮肤站的皮肤和披风。
* 多个账号可以共存，点一行就能切换。


四、Java
----------------------------------------------------------------------
启动器会自动找你电脑上装过的 Java（8 / 17 / 21 / 25 都可以）。
如果某个版本需要的 Java 没有，而且设置里「自动下载」是开的，
它会自动从 Mojang 官方下载一份运行时（约 180 MB，只在第一次需要）。

也可以自己去设置页「Java 运行时」里手动检测 / 下载：
   填大版本号（8、17、21…）→ 点「立即下载」。


五、Mod / 资源包 / 光影 / 整合包
----------------------------------------------------------------------
界面只有三个大入口：开始 / 下载 / 设置。

* 想在游戏里用的内容（模组、资源包、光影）：
  点「下载」→ 上面的「模组 / 资源包 / 光影」页签 → 直接搜（支持中文，
  例如搜「小地图」「优化」「光影」）→ 右边选版本 → 「下载并安装」。
  装好的东西会自动出现在当前实例对应的目录里。
* 管理已装的模组：「开始」→「模组」页签。可以切内容类型、
  启用 / 禁用（改后缀）、删除、导入本地文件、打开目录。
  上面的「下载」按钮会跳到下载页对应页签。
* 把 .jar 直接拖进窗口 = 装进当前实例的 mods 目录。
* 把 .zip / .mrpack 拖进窗口 = 自动识别格式（Modrinth / CurseForge / MultiMC / 散装）
  并安装成一个独立实例；CurseForge 包里的模组会自动下载（不需要 API Key）。
* 「安装整合包…」可以从 Modrinth 的整合包市场里挑。
* 实例隔离：设置里打开后，每个版本有自己的 mods / 存档 / 配置；
  整合包永远是隔离的。


六、其他功能
----------------------------------------------------------------------
* 存档：开始页选中版本 →「存档」，可以备份成 zip、恢复、删除、打开目录。
* 校验：开始页 →「校验」，检查文件是否完整，缺的一键补。
* 导出：开始页 →「导出」，把当前实例导出成 .mrpack 分享给别人。
* 启动日志：开始页右下角那块，点标题可以折叠 / 展开。
* 崩溃诊断：游戏崩了会自动分析日志并给出可能原因；也能一键打包反馈 zip。
* 主题：设置页「界面」里可以切 PCL 浅蓝 / 暗色 / 亮色 / 深蓝 / 护眼绿，点了立即生效。


七、文件都放在哪
----------------------------------------------------------------------
* 启动器配置：%APPDATA%\MCLite\config.json
  （%APPDATA% 就是 C:\Users\你的用户名\AppData\Roaming）
* 游戏文件：你设置里那个「游戏目录」
* 启动日志：<游戏目录>\logs\mclite-<版本>-latest.log
* 想彻底删掉：删掉 exe + 上面那个 MCLite 配置文件夹即可（游戏存档不会动）。


八、常见问题
----------------------------------------------------------------------
Q: 双击没反应？
A: 先看任务管理器里有没有 MCLite.exe。没有的话可能是被杀毒软件拦了，
   把 exe 加进白名单再试；也可能是解压时文件被占用了。

Q: 下载很慢 / 一直卡住？
A: 设置页把「下载源」切成 BMCLAPI 镜像，再试一次。

Q: 启动游戏报错 / 闪退？
A: 看「开始」页下方的启动日志；崩了会自动弹崩溃分析。
   也可以去「设置」→「一键反馈（打包日志）」生成一个 zip 发给帮你排查的人。

Q: 支持什么系统？
A: 64 位 Windows 10 / 11。需要能联外网（下载版本和 Java）。

Q: 会改我的电脑设置吗？
A: 不会。只在自己目录里读写文件，不写注册表、不需要管理员权限。
